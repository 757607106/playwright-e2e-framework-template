# 业务测试计划

## 任务与环境

- 目标业务与本次范围：
- 应用仓库、目标 project、拟生成的 spec：
- 环境名称及只读/可写范围（不含凭据）：
- 角色、认证方式和隔离依据：
- 需求及契约来源：
- 已有用例与可复用适配层：

## 场景

每个场景填写以下内容，可按实际任务增减场景。

### pageId / scenarioId：

- 场景名称与业务目的：
- 需求引用（无编号时明确说明）：
- 前置状态及数据来源：
- 已观察的页面入口、定位依据与证据来源：
- API 方法、路径、请求/响应契约与来源：
- 操作步骤：
- 预期可观察的业务结果及判定依据：
- 后端或持久化验证（不可用时说明证据范围）：
- 数据创建、准确 ID 获取与即时登记位置：
- 清理/恢复操作、结果验证及不可逆副作用：
- 覆盖等级与业务/support/exclude 分类依据：
- 独立运行与账号/数据隔离：
- 未确认内容：

## 审查与执行范围

- 当前计划审查状态和已有授权依据：
- 允许执行的环境、场景及写操作：
- 尚需确认的信息或权限：
- 静态检查与目标执行命令：

## 执行后回填

- 实际命令、环境与时间：
- 通过/失败/未执行/flaky 情况：
- 报告和诊断证据位置：
- 清理结果及未解决的准确资源 ID：
- 剩余问题与下一步条件：
